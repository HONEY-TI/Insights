## Contexto / Problema

As configurações do Dev Container, do Docker Compose e das tarefas do VS Code precisam ser
atualizadas para manter o ambiente de desenvolvimento e a sincronização do workspace alinhados.

## Objetivo

Consolidar os ajustes atuais de infraestrutura local e automação do workspace, preservando um
fluxo reproduzível para inicialização e sincronização.

## Critérios de aceite

Rascunho — revisar e complementar manualmente conforme a validação funcional das alterações.
