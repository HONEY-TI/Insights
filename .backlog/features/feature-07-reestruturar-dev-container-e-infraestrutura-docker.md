## Contexto / Problema

O ambiente de desenvolvimento precisava alinhar a imagem base, a inicialização do
workspace, o acesso gráfico e a infraestrutura Docker compartilhada.

## Objetivo

Reestruturar o Dev Container para inicializar o workspace de forma previsível,
aplicar as regras de rede necessárias e integrar os componentes auxiliares do
workspace.

## Critérios de aceite

Rascunho — complementar manualmente durante a revisão da feature.
