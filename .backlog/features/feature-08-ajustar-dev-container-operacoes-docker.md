## Contexto / Problema

Rascunho: a configuração atual do Dev Container e dos fluxos Docker precisa alinhar
o ciclo de inicialização, o acesso ao shell, o repasse de credenciais e a limpeza
de recursos.

## Objetivo

Rascunho: ajustar a configuração do Dev Container, a ordem de inicialização e as
rotinas Docker para um ambiente mais previsível e operacional.

## Critérios de aceite

Rascunho: revisar manualmente durante a revisão da PR.
